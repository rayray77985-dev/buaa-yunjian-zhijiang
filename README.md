# 云笺致疆 · 项目介绍网页

北京航空航天大学蓝天志愿者协会常设项目展示。纯静态网页，不依赖外部 CDN，不需要登录。

## 内容与来源

- 项目简介、结对与收发流程：协会提供的项目介绍、立项材料和培训资料。
- 志愿者采访图片与摘录：[协会往期推送](https://mp.weixin.qq.com/s/SETzSyfVuSjY_WNef-5LYg)，2026 年 3 月 22 日。
- 蓝小咕：协会提供的原创素材。
- 信封、信纸、邮戳、明信片山景和连线：原生 CSS/SVG 绘制。互动区明确标注为话题示意，不是真实学生来信。
- 页面不将往期招募日期、名额、志愿时长或个人联系方式作为当前招募信息。参与方式以公众号当期通知为准。

## 使用

仓库根目录部署到 GitHub Pages main 分支，保留 .nojekyll。

本地预览：`python3 -m http.server 8766`

分享二维码在 assets/share-qr.png，弹窗二维码也在浏览器本地生成。二维码指向本项目的 GitHub Pages 地址。

## 无障碍与动效

支持键盘操作、原生分享对话框、减少动态效果偏好和 320px 起的响应式排版。滚动浮现只发生一次，阅读进度按动画帧更新。没有外部跟踪脚本。

二维码库 qrcode-generator 的 MIT 许可位于 vendor/qrcode.LICENSE。

## 活动照片相册

使用协会新提供的 16 张活动照片：读信与书写 2 张、书信往来 7 张、信封与细节 7 张。另 1 张电视剧评论区截图与活动无关，未纳入。照片均保留全幅供大图阅读，缩略图与阅读图分别优化加载。两张现场照片也嵌入书信旅程。

支持分组、原生滑动与键盘翻阅、手动开启的每 8 秒慢放、全屏大图、缩放和拖动。照片说明描述可见画面，不推断拍摄日期或信中人物身份。
